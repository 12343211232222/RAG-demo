# VPN 接入指南

## 申请账号

员工在 IT 门户提交“VPN 账号申请”工单，审批通过后 1 个工作日内开通，账号与域账号绑定。

## 客户端配置

客户端网关地址为 vpn.example.internal，端口 8443，协议选择 SSL-VPN，首次登录需绑定动态口令。

## 连接失败排查

连接失败时，首先检查客户端版本是否为 5.2 及以上，旧版本已停止支持；然后检查本地网络是否能访问网关 8443 端口。
