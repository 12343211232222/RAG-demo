# API 错误码手册

## 通用错误码

E1001 表示系统繁忙，请稍后重试；E1002 表示鉴权失败，即签名或访问令牌无效，请重新获取令牌。

## 限流与配额

E2001 表示请求被限流，即每秒请求数超过 100 次的速率限制；E2002 表示配额用尽，即当日调用总量额度耗尽。限流是速率概念，配额是总量概念，二者互不相同。

## 熔断提示

连续触发 E1001 时网关将自动熔断，熔断恢复时间见值班手册。
