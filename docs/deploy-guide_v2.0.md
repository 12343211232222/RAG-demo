# 生产发布指南

## 基本流程

提交发布单，自动化测试通过后部署预发环境，确认无误后发布生产环境。

## 灰度条件

当服务开启灰度开关（feature-flag）时，发布流程适用本节的附加条件。

附加条件如下：必须先在预发环境连续观察 24 小时，且由值班负责人二次确认后方可生产发布。

## 冻结期

目前不设发布冻结期，任何工作日均可发布。
